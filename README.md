# ParametricDesign

Describe a design to any LLM using our skills, then open the result in a desktop app
to view it in 3D, fine-tune its parameters, measure it, and export STL / 3MF / STEP /
OBJ / GLB. A catalog website hosts and categorizes community designs, with in-browser
preview and simple customization.

Status: planning. See [docs/SPEC.md](docs/SPEC.md) for the product and technical spec.
